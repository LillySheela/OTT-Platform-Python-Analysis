# OTT-Platform-Python-Analysis

A comprehensive data analysis for a leading global streaming platform to uncover trends in content type, release patterns, audience engagement, and top performers. The analysis provides data-driven recommendations for content acquisition, marketing strategies, and audience retention.

## 🔹 Key Features
- Exploratory Data Analysis (EDA) on content metadata including type, genre, rating, country, director, and cast.
- Visualizations of content distribution, release trends, top performers, and release timing.
- Actionable insights for strategic decision-making in content production and engagement.
- Portfolio-ready Python notebook with clean, reproducible code.

## 🔹 Technologies Used
- Python: Pandas, NumPy, Seaborn, Matplotlib
- Data Visualization & EDA
- Colab Notebook
- Excel / CSV data handling

## 🔹 Insights & Recommendations
- **Content Type:** Movies dominate (~69%) vs TV Shows (~31%). Recommend maintaining movies as core while strategically expanding TV shows to boost retention.
- **Release Trends:** Surges in 2017–2020 highlight production scaling opportunities. Early years show low acquisitions, helpful for forecasting.
- **Genres:** International Movies, Dramas, Comedies lead; niche genres underrepresented. Suggest targeted content acquisition.
- **Top Performers:** US & India produce most content. Collaboration with prolific directors & actors can drive engagement.
- **Release Timing:** Fridays are optimal for major releases; mid-week for niche content to sustain engagement.

## 📂 Folder Structure
- `data/` – dataset CSV files
- `notebooks/` – Jupyter notebooks with EDA and analysis
- `visuals/` – charts & figures generated from analysis
- `src/` – Python scripts for cleaning, EDA, visualization, and insights
- `reports/` – executive summary PDF for stakeholders

## 🔹 Usage
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Open `notebooks/streaming_platform_analysis.ipynb` in Jupyter or Colab.
4. Run cells sequentially to reproduce analysis and visualizations.
